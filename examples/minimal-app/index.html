7. 菜单与托盘（R9 主窗能力 + 点击回传）

        

          点一次菜单项后，宿主经 Tauri 事件通道（AppHandle::emit，
          不是 host_events_drain）把
          { id, source, native: true } 发到 MENU_CLICK_TOPIC， 本页
          listen 它并把帧打在下面。托盘右键菜单的点击与菜单点击共用
          宿主那一个全局监听，差别只在 source: "tray"。非 Tauri 宿主 /
          缺省装配时这些命令如实返回 Unsupported，不会假装弹出。
